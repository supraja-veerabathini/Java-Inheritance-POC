# Java Inheritance POC – Banking Application

## Project Overview
This project is a Java-based Banking Proof of Concept (POC) developed to demonstrate Object-Oriented Programming (OOP) concepts, particularly **Inheritance and Method Overriding**, through a simple loan management scenario.

The application represents different types of loans, such as Personal Loan and Home Loan, using a parent-child class relationship.

## Technologies Used
- **Programming Language:** Java
- **IDE:** Eclipse
- **Concepts:** Object-Oriented Programming (OOP)

## Project Structure

```text
Java-Inheritance-POC/

```

## OOP Concepts Implemented

- **Inheritance:** Reusing properties and methods of the parent Loan class in child classes.
- **Method Overriding:** Providing specific implementations of inherited methods in child classes.
- **Code Reusability:** Avoiding code duplication through inheritance.
- **Runtime Polymorphism:** Demonstrating different behaviours through parent and child class references (where applicable).

## Application Modules

- **Loan:** Parent class representing common loan-related properties and behaviours.
- **HomeLoan:** Child class representing a home loan.
- **PersonalLoan:** Child class representing a personal loan.

## Project Objective

The main objective of this project is to understand how inheritance simplifies code organization, improves reusability, and supports extensibility in Java applications.
